# MCP-Mod Analysis

Model-based dose-response analysis using Multiple Comparison Procedures-Modelling (MCP-Mod) framework. This project implements simulations and statistical methods for Phase 2/3 clinical trial design and analysis.

## Overview

MCP-Mod is a general statistical framework for dose-finding and dose-response analyses. It combines multiple comparison procedures with model-based approaches to efficiently identify optimal doses while controlling for multiple testing.

## Features

- **Phase 2/3 Simulations** - Calculate probability of success under various dose-response models
- **Dose-Response Modeling** - Multiple parametric models (linear, quadratic, exponential, etc.)
- **MCP-Mod Framework** - Combined approach for dose-finding
- **Sample Size Planning** - Design calculations for Phase 2/3 studies
- **Adaptive Methods** - Support for adaptive trial designs
- **Biomarker Analysis** - Dose-response analysis for biomarkers

## Technologies

- R
- Statistical Modeling Packages (DoseFinding, MCPMod, etc.)
- Quarto/RMarkdown for reproducible analyses

## Project Contents

- **MCP-Mod Implementations** - Various parametric dose-response models
- **Sample Size Calculations** - Phase 2 and Phase 3 power calculations
- **Clinical Trial Simulations** - Monte Carlo simulations for trial design
- **Biomarker Analysis** - Dose-response for efficacy and safety biomarkers
- **Dose-Finding Analyses** - Practical dose-finding workflows

## Key Analyses

- Binary endpoint dose-finding
- Continuous endpoint analyses
- Time-to-event dose-response
- Biomarker-based dose-finding
- Adaptive dose-finding designs
